LLM inference has two phases: **prefill**, which processes the entire prompt in parallel and is compute-bound, determining time to first token; and **decode**, which generates one token at a time and is memory-bandwidth-bound, since each step must stream all model weights and cached key/value projections through memory for minimal arithmetic. The KV cache avoids recomputing attention over prior tokens but grows linearly with context length, competing with model weights for memory — a critical constraint on unified-memory machines like Apple Silicon.

Speculative decoding accelerates decode by decoupling token proposal from verification: a cheap mechanism drafts several candidate tokens, and the target model verifies them all in a single forward pass. Accepted tokens are free throughput gains; rejected ones trigger a fallback to the model's own prediction, preserving output quality exactly. **Multi-Token Prediction (MTP)** is a variant that embeds extra prediction heads directly into the base model, eliminating the need for a separate draft model's weights in memory.

The decisive metric is **acceptance rate** — the fraction of drafted tokens accepted. It varies by workload: code generation yields higher rates than free-form prose due to its structured patterns. Hardware architecture also matters: GPUs with high compute-to-bandwidth ratios (e.g., NVIDIA CUDA cards) realize larger speedups than Apple Silicon, where unified memory shares bandwidth across CPU, GPU, and OS. Consequently, MTP and speculative decoding benefits must be measured empirically per model, quantization, and hardware, not assumed from benchmarks on different platforms.
