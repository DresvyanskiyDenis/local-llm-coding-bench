# Task: implement a fixed-capacity LRU cache

Implement the `LRUCache` class in `src/solution.py`. The exact behavior of
`__init__`, `get`, and `put` (including eviction rules and what counts as
"using" an entry) is specified in that file's docstring — read it carefully
before writing code.

Requirements:
- Pure Python, no third-party dependencies.
- All operations must run in O(1) amortized time.

When you are done, `src/solution.py` should contain a complete, working
implementation of `LRUCache` (no `NotImplementedError` left behind).
